# SRAM-RTL-Design-and-Verification

## Overview

This project focuses on the functional verification of a Single-Port SRAM using an object-oriented SystemVerilog testbench architecture. 

The verification environment was used to validate the memory's read and write functionality through constrained-random simulation, automated checking, and functional coverage monitoring.

---

## Objectives

- Verify Single-Port SRAM core design functionality
- Execute constrained-random verification test cases
- Perform data integrity verification using a self-checking scoreboard
- Perform simulation and debugging using ModelSim/QuestaSim

---

## Technologies Used

- SystemVerilog
- QuestaSim

---

## Verification Components

- Generator
- Driver
- Input Monitor (imonitor)
- Output Monitor (omonitor)
- Scoreboard
- Coverage Collector
- Transaction Packet
